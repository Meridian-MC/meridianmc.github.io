Economy

Meridian runs a free market. Almost everything in circulation was gathered or made by a player, and prices are whatever players agree to. Here's how it works.

What's the currency?

A single currency, written $, not tied to any physical item. Everyone starts with a $2,500 balance. Check yours with /balance and send money with /pay <player> <amount>.

Is there a server shop?

Yes, but it only sells basic commodities like torches and bread. There are no player-to-server sell options — you cannot dump items on the server for cash. This is deliberate, to keep the market free.

Why is the server shop so expensive?

Prices there are set high on purpose, to push players toward trading with each other instead of the server.

How do I make money?

Mainly by trading with other players. Chest shops are the real economy — left-click a chest with the item you want to sell to set one up. Find what's in demand, produce it, and sell it. There is no single get-rich-quick method.

Are there jobs I can do for money?

Yes. A small set of jobs — currently Miner, Farmer, Fisherman, Hunter, and Explorer — pays out for relevant actions, mostly to help new players earn starting capital. Daily earnings are capped at $1,500, so jobs are not a full-time income. Run /jobs browse to get employed.

How should I price my items?

Players set their own prices — there is no fixed price list for anything traded player-to-player. Check a few shops, see what people are asking, and price accordingly.

Scamming through a mispriced shop sign is on the buyer to catch. Scamming through trust — taking a payment and not delivering, fake middlemen, “hold this for me” — is a Rulebook violation. For big deals, use a chest shop or ask staff to middleman.
